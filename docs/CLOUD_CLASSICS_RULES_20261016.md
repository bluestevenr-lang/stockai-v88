# 2026-10-16 云端规则复核与稳定研究名单

用户最新指令优先：分析逻辑保存到 GitHub，既有 Actions 云端以确定性规则复核；页面读结果，不因打开、刷新或每轮筛选调用模型。本次新增链路 `model_calls=0`，没有付费回退。Muse 保留三时段与按需独立验证，系统规则结果不冒充 Muse 裁决。

## 当前变化与原因

- 旧名单只在盘中锁定，新完整交易日重新抢排名；普通发行审核问询还可能被误判为治理风险。`3a-daily-research-v2` 保留当前合格研究席，挑战者须连续两个完整交易日领先同一席至少 3 分。缺源逐股待核，明确风险即时退出，不冻结整个市场。各市场最多 3 只、同业最多 1 只。初选仍按原统一分；稳定研究名单不是实时最高分排序。详见 `RESEARCH_ROSTER_STABILITY_20261016.md`。
- 买点不足或跨层证据冲突只改为重点观察，不因新增技术指标清空 3A。原统一分、5%净空间/2净收益风险比、原目标、止损、期限与历史不变。
- 旧板块叙述把一个快照内的 5/20 日排名差异写成跨日轮入/资金流。新版按同市场固定基准与同一完整日期比较，分开相对超额和自身涨跌；跨日状态需要真实连续观察确认。没有资金流数据不称资金轮入。

## 规则与证据

| 检查 | 实际实现 | 不作的推论 |
|---|---|---|
| 顾比 GMMA | 短组 3/5/8/10/12/15、长组 30/35/40/45/50/60 EMA，方向、分离、缠绕 | 不能仅凭均线自动买入 |
| 日本蜡烛图 | 有前置趋势和位置的吞没、锤子形态，下一完整交易日确认 | 未确认形态不算成功信号；不声称穷尽全部蜡烛形态 |
| 专业投机的结构/风险原则 | 已确认高低点、趋势结构、ATR14 与原止损带距离；确认左右各两根完整K线 | 不声称完整复刻原书；不移动原止损或把1ATR当最优止损 |
| 聪明的投资者的价值原则 | 可追溯的经常性利润、同期间同币种经营现金流、估值事实；多年质量和安全边际缺证独立标注 | 低PE/PB、一期高增长不证明便宜或具安全边际 |
| 量价关系 | 最新完整日量/此前20日均量、5日与此前15日均量、20日价格方向 | 缺量不补1；技术指标同源不算多份独立证据 |
| 大盘→板块→个股 | 同日期基准、明确行业映射、板块5/20日绝对与相对方向、个股GMMA+结构 | “同向下跌”不等于可以买；未覆盖行业不借用泛指数补证 |

逆势保留研究但明确冲突。只有可追溯公司公告原文、身份、日期、抓取时间、原文摘要与哈希齐备，才显示“已有催化待复核”，仍不自动解除入场条件。普通财报增长描述不充当新催化。

止损比较要求原计划 `price_plan_basis` 与技术序列口径明确且逐字一致。旧计划无口径时保持待核，不回填假元数据，不改变 Astra plan_id 或任何价带。ATR 噪声提示、未确认止损锚及趋势冲突阻止标成可买，不自动转为卖出指令。Astra 已到期、止损、退出状态不被新检查改回研究。

固定参数属于工程约束，不是书籍原话或已证实收益优势。GMMA、K线、量价、枢轴来自同一行情家族；企业原始财报和外部 Muse 核查分别注明来源。

## 流水线和展示

`autonomous.yml` 的既有免费行情 → `strategy_board/astra_cycle.refresh` → `strategy_multicheck.enrich` → 既有运行包/公开投影与 `review-exchange/latest/screening.json`。只对选定 3A/Astra 做本轮复核，不逐股调用模型。保持运行包 FILES=18。完整任务先更新大盘板块，再筛选；仅板块刷新 `rotation_only` 永远不触发发送或改正式草案。

网页的 3A/Astra 行增加一行趋势关系和可展开的五类依据；时间、数据源、缺项与冲突清晰展示。跨完整交易日的旧结果标“历史核查”，不更新其事实时间。飞书正文增加同源简短规则核查说明；正式草案仍整份冻结。新增事实进入 Muse 的 item_sha256；旧通过徽章不继承，旧回执不回改。

所有推荐日历使用同一计数模块：同市场同代码、当月截至该日，按不同推荐日累计；同日多模块/多次刷新只算一次。显示 `名称*3`。日后回看不把未来推荐次数写回早期日期，随访/退出不冒充新推荐，底层记录不删。
