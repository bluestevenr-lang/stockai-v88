# V88 3A分类与等待标记（2026-10-11）

用户已确认：3A既包括当下条件符合的高分股票，也包括最高优先级价值研究。研究价值与入场时机必须分别展示。

- 统一分和权重不随短中长周期重复变动。3A≥80且有企业依据，2A为60–<80，1A为50–<60；周期另列。高分短线进3A后不得自动延长持有期或扩大止损。
- 每个市场3A两类合计最多3只，分数降序并保留行业去重；2A、1A各最多3只。不得为凑满数量补造数据或通过条件。
- 趋势已核且在价带外：明确“趋势符合 · 等待进入买入区”，展示到价带的真实距离及剩余条件；不能把未知趋势称为符合，也不能将远离价带称为即将。
- 新鲜实时报价在价带内、全部条件已通过：明确“高分 · 买入条件已满足”。休市只可说“收盘条件满足 · 等待开盘复核”；旧报价或资料不足必须等待。
- 数据缺失保留原研究及原时间，不能把旧记录刷新时间冒充重新算分。完整有效的负面复核不得靠旧研究覆盖。
- 保留现价、币种、报价时间、入场/止盈/止损、真实周期、行业Top5。历史记录不删除，3A研究不冒充成交或盈利预测。
