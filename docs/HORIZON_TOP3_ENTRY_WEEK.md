# 三周期3A研究榜、入场核验及候补规则（2026-09-13）

本次用户要求覆盖此前的周期展示、强制市场配额及先按入场条件过滤研究榜的规则。

## 研究窗口与真实评级

| 独立研究榜 | 前瞻研究窗口 | 数量 |
| --- | --- | --- |
| 短期3A | 从现在到未来8周 | 三市场合计最多3只 |
| 中期3A | 未来8–24周 | 三市场合计最多3只 |
| 长期3A | 未来12–36周 | 三市场合计最多3只 |

中长期窗口有意重叠；它们是分别核证的研究问题，不是互斥时间桶。没有对应周期的审核，不复制另一周期股票或分数来补齐。3A是模块名称，行内始终显示真实1A/2A/3A等级。只有当前有效同包双审、书理与收益合同一致的记录可进入研究精选，过期/缺审/分数矛盾不得入榜。

`research_window`保存新研究窗口与原合同覆盖信息；源审核的策略周期用于归属，禁止用“本周能否入场”改变归属。原已签审计仍按当时的短1–30日/中31–90日/长91–365日交易合同验证，未经新事实与双审，不把期限和目标延长至新的完整研究窗口。页面在每行明确折叠显示原合同期限及“后续阶段逐次补证复审”。新研究窗口是持续观察议程，不声称旧审计已经验证整段8/24/36周。

## 一条排序，两种状态

每个研究榜按原中央审核分降序，同分依次比较原书理分、待确认项数、净收益风险比档、净空间相对原门槛档、规范股票代码。等级徽标保留，但不让低分先于高分。短中长期分别最多3只，绝不相互挤占。

研究精选 → 本周入场核验 → 原量价触发与执行许可，是独立字段。入场冲突仍可保留研究精选，行内显示“暂不入场”与精确原因；不能把该行当成当前买入推荐。688002.SS现有短期机会留在短期榜，原评级/70分/入场161.232–164.27/失效153.41/目标185.96–185.99继续引用同包原文；趋势恢复与净RR约束没有交集时仍禁止新开仓，不改价凑通过。

周度入口只取短期研究榜中通过周内条件的子集，并显示主榜原名次。深度、网页、飞书均读相同原合同、审核分及`entry_opportunity`，不重新授级。研究入榜不自动变成周度买入许可。

## 候补统一限额

已评级未进Top3、尚未复审线索、暂停的连续跟踪，先合并去重，再按每市场最多5只截断，总计不超过15只。真实有限审核分降序，有分在前；未审无分记录排后，按本地缺证/书理初筛及固定顺序排列，不填造分数。相同身份用当前数据源覆盖旧连续记录，不以更大的历史分替换新低分。

前端与后端共同执行候补数量上限。候补默认折叠；未进入候补的完整评级历史仍在档案和个股深度，不再追加到候补表。上次上榜保留原范围、政策版本及真实时间；同版刷新不重复记次。

## 五交易日入场与后台一致性

`entry_opportunity → entry_week`先取原入场区间、确认价、失效线、原目标与净RR约束的交集，再核下一5个本市场交易日及确认步骤能否容纳。读取近120个完整交易日24个不重叠5日块，至少20组，按1–5日预算取上涨/下跌收盘幅度中位数作为历史波动情景；不是到价概率。未知模板、近期缺日、停牌、日期或价格基准冲突不通过。一阶段预留1日、两阶段3日；原截止日不顺延。

20日平均当地成交额最低A股2000万、美股500万、港股500万，是现有V88入场参数，不再拿它删除有效研究评级。取消旧固定距离10%的到价判据。交易单位/下单实际价格仍须核验，研究价格带不授权下单。

`entry_week_pub.json`原始来源哈希、规范化整段行情与数据库校验一致，绑定股票、审核ID、原合同、原来源时钟。四位价格表示误差只允许0.000051，不放宽交易条件。

当前版本：`grade-focus-v7-research-windows` / `central-research-window-top3-v6` / `entry-week-v2`。后台现有刷新及飞书本地投影复用同版结果，无新增模型/数据调用，不因刷新修改原行情日期。月度收入只能以实际买卖结算净收益验证。
