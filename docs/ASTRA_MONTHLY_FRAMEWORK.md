## 六道滤网与具体输入

顺序保持：趋势→盈利→估值与期限→催化→波动→交易单位。每项记录PASS/FAIL/MISSING和第一个阻断点，完整缺口同时保留，不把缺数据当作已否定。

1. 趋势：同源价格=当前中央合同现价，价格>MA50，相对60日收益>0且明确触发。缺触发是研究状态，不执行。
2. 盈利：TTM EPS>0，最新可比EPS同比增速>上一期≥0，营收增长>0，两期官方财报来源与可比口径完整。这是本月成长趋势策略，不能机械要求所有价值/周期股也用相同盈利模板。
3. 估值/期限：中央短期合同净空间已通过，独立目标下沿覆盖原止盈下沿，兑现交易周期不超过本月余下时间，来源必须同为短期；列出反例，不用分析师年度目标代签。
4. 催化：本月官方可核事件，或近7日已落地事件；“事件会发生”与“方向利好”分开。不持仓穿越未经专门审核的二元事件风险。
5. 波动：结构止损固定；ATR20、历史跳空95分位、流动性有源。跳空预留至少覆盖观测值，承认尾部可更差。不能称最大亏损确定封顶。
6. 仓位：真实可用现金、原中央合同允许的最大名义额、账户剩余风险、当期最小股数/申报增量、费用与汇率齐全。缺任何项不生成仓位。

当前来源新鲜度工程上限：趋势/波动72小时，盈利120天，估值/事件/申报单位30天；交易费用与账户余额须当日对账，换算汇率24小时。实际触发执行还受中央更严格行情时效约束。

## 仓位计算

设报价币种到风险预算币种的汇率为f，入场上沿P、原失效价S、止盈下沿TP，买卖费率b/s，每股跳空预留J，往返固定费用F：

- 每股计划风险 U = [P×(1+b)−S×(1−s)+J]×f。
- q_raw = min[(现金预算−F×f)/(P×(1+b)×f), (剩余风险预算−F×f)/U]。
- 若q_raw小于最小申报量则q=0；否则q=最小量+floor[(q_raw−最小量)/增量]×增量。
- 目标情景净收益=q×[TP×(1−s)−P×(1+b)]×f−F×f。此数不计入本月已实现进度。

目标核算独立展示剩余净收益目标、本笔止盈情景覆盖率、未覆盖差额及剩余开仓次数。不得把两次开仓名额当作两次获利，差额不触发加仓或放宽风险。美元原计划额度2000与目标200仅给出10%的需求参照，不代表可实现月收益。

固定费用保守全额预留；无融资、无为了目标提升额度、无为了股数缩止损。每个入场批次必须保留原区间、止损、目标、原论文截止日与中央审核编号。新月度合同退出截止取原期限与本月末中较早者，只能收紧，不能延长或改写旧成交合同。

## 月度状态机

全部月份判定使用上海政策日历。调用者传入的带时区时间先转换到上海，避免 UTC 仍为上月底而本地已经进入新月时误锁已对账账本；无时区参考时间不能确认账本。亏损止损原因按去首尾空格、忽略大小写后识别 `stop`、`stop_loss` 和 `止损`，原成交原因保持不变。上月买入、本月发生的亏损止损也按本月交易身份计数；不能因为本月新增开仓数为零而绕过停手规则。

成交台账未知/过期→LEDGER_UNVERIFIED，损益和止损次数显示“未核实”，不能自动填0。
对账有效→OPEN，仍需六道筛选和当前中央3A。
两次亏损止损或实际累计亏损耗尽月预算→MONTH_STOPPED；本月锁定，不因刷新/删减台账恢复新开仓权限。
仅未平仓风险占满剩余预算→RISK_RESERVED，当前不新增；风险释放且其它条件合格后可重新评估，不把预留风险误记为已亏损。
本月两次实际开仓→ENTRY_LIMIT；替补不绕过次数/仓位限制。
已实现净收益≥本月目标→TARGET_DONE；浮盈/未成交收益不达标。

已实现盈利不补回消耗的风险预算；部分卖出也按原始凭证计入实际盈亏。重复成交凭证拒绝计算。新月必须重新对账，不能只改月份重置旧持仓风险。已有仓位的保护措施在所有状态继续。原始风险R、成交凭证及30分钟内的含费未实现盈亏齐全时，系统计算浮盈R倍数，达到1R列出利润保护复核；估值过期则明确待核实。该提示不自动移动止损，也不计月度已实现进度。
