## v2规则

1. `research_roster.policy=3a-daily-research-v2`，兼容读取v1既有入选记录，首次迁移不重新选股、不更改原入选时间或分数。
2. 每个市场仍最多3只、行业去重。每日按该市场最新完整交易日逐席评审；原席仍满足当前分≥80及企业依据则优先续列。名单是稳定重点研究，不是实时最高分Top3。
3. 挑战者须连续两个相邻完整交易日，比分数最低的可替换席领先至少3分。同业挑战只能替换同业席。新候选/原席缺完整当日结构、条件失效、跳过交易日或目标席改变，连续计数清零或从1重计。一天反复扫描不增加天数。周末/法定休市通过各交易所日历判断，不机械用自然日。
4. 真正空席可从当前原规则合格池补充，不人为等待两天。当天分数跌破80仍只留研究且不可买；下次有完整数据的日度评审未达80则退出。确认的财务反证、风险警示名称和治理风险随时退出。
5. 缺源只挂起该席，保留真实原时点和未验证标记；其他完整席正常评审。数据返回时补做该席尚未完成的日度检查。不得以缺源为公司恶化，也不能让一个坏源无限阻塞整个市场。
6. 普通发行审核问询、问询回复标题不单独构成治理硬退出。明确未回复重大问询、立案/调查、否定/无法表示审计意见、未清偿等实质风险仍退出；结构化`hits[].hard_risk=true`保留否决。对普通问询原来的入场待核状态保持，不由研究续列推断可买。

## 字段与审计

- 根：`policy / score_margin=3 / confirmation_sessions=2`。
- 每市场：`review_session / reviewed_at / checked_at / pending_codes / review_deferred`；`challengers[code]`记录`against_code / first_session / last_session / streak / score_gap / candidate_score / incumbent_score / checked_at`。
- 每股：原`selected_at / selection_score / selection_reason`不变；新增`selection_session`保留原入选评审日，`last_review_session`表示该席最近实际成功资格复核的完整日；`review_session`绑定当前名单版本。真实`current_score`和`score_current_unknown`独立更新。
- `changes`是本轮变化；新增`change_history`累计本次迁移以后所有进入/退出及原因，不删除旧历史、不倒填缺失的旧轮原因。被挑战替换的入选记录带`replacement_evidence`。
- 网页/飞书仍必须明确入选分、当前分或待核、真实现价/币种/报价时间。`instant_top3`仅作研究参考，不另造一组主要名单。
