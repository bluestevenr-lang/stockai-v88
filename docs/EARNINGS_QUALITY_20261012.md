# 2026-10-12 经常性利润与入场状态修正

本次保留 v8 的 3A 最高分研究名单与每市场 Top3/行业去重；不因当前买点不足取消高分研究。统一分权重、5% 当前净空间、2 倍当前净收益风险比均未更改。未做自动调参，不声称胜率提高或已通过样本外绩效验证。

## 根因与行为

旧版基本面用报表归母利润增速、ROE 和盈利收益率评分，无法分辨一次性收益；“字段覆盖100%”也容易被误读为质量已核。现在同证券、报告期、币种及归母利润对账通过后，用扣非利润增速、扣非 ROE 和扣非 EPS 替换对应评分输入。原报表数字仍保留。数据商数据不冒充公告原文复核。

东方财富免费批量财务补充接口仅请求9个必要字段；本地实际约6.84秒匹配5,659只A股，其中5,594只通过完整字段及口径检查，65只仍待核。每轮补充最多60秒/12页，失败保留同一财报快照的原证据；不同报告期或币种不得继承。港美股没有可对账的经常性数据时，原口径分只能作为明确标注的暂存研究分，不能凭headline净利增长授予可买状态。不能仅凭营收下降、净利上升就断言存在一次性收益。

所有档位入场资格新增利润质量检查。已核经常性亏损/主业反证不能被旧的“有企业依据”布尔值覆盖；未知不等于已证伪，仍可保留3A研究名单。网页、深度页、公开投影、飞书正文使用同一质量说明与等待条件。旧缓存的可买标志也须重新经过此检查，不改写旧回执或历史评级。

只有剩余缺口确实仅为价格尚未进入区间时，才显示“趋势符合·等待进入买入区”。公告、利润质量等仍待核时，必须说明不只是等待价格。当前首段结构空间和原计划情景收益继续分列。评分字段覆盖不等于质量通过率。

## Muse 第二轮讨论：待验证的扩展，不是本轮已上线规则

1. 研究资格现有退出依据为统一分跌破80、企业依据被反证或排序/行业席位被更优合格对象替代。建议增加月度可跟进性复核：长期无可交易结构时可以移入永久跟踪，释放Top3展示席位，保留原评级沿革；不任意设“负空间N日即降级”或降低门槛。N、轮换频率与成本影响须先回放/样本外验证。
2. 当前财务增长主要用最新一期同比（利润增速贡献有60%上限），没有三年中周期处理。扣非并不等于周期调整。建议对周期行业同时看TTM、跨年经常性利润与经营现金流，并核对价差/产能周期；不机械以三年平均替代所有行业的增长指标。Muse所述具体公司全年数字及一次性项目需原文核验。
3. 交叉验证台账建议以原计划ID为样本键；字段包括证券/市场、发布与行情时间、规则版本/快照/投递ID、原始入场带/结构目标/情景目标/止损/期限、双方独立结论和证据、实际触发与成交假设、费用/复权口径、结果/净R/MFE/MAE。研究未入场、入场后交易结果和单纯目标价触及分别统计。Astra原15交易日观察窗与每月1/10/20重算日是两项规则；3A月度复核并按原计划到期结算，不自动延期。同计划重复日报不增样本；同日止盈止损先后未知单列，所有分歧/失败/缺数据样本都保留。
4. 当前仅有recovery投递ID，尚未增加显式supersedes字段。建议新回执追加supersedes=被替代delivery_id；保留旧记录原义，仅新回执complete=true且accepted=true时替代正式统计资格。debug记录单列，不默认替代正式报告。此项还未实现，不把建议写成验收结果。
